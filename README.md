# yWorks Claude Code Marketplace

The official yWorks marketplace for Claude Code plugins — graph visualization, diagramming, and yFiles for HTML development tools.

## Getting Started

Add this marketplace to Claude Code with a single command:

```bash
/plugin marketplace add yworks/yfiles-claude-marketplace
```

Then install any plugin from the marketplace:

```bash
/plugin install yfiles-for-html@yfiles
```

## Available Plugins

### yfiles-for-html

[Plugin Repository](https://github.com/yworks/yfiles-for-html-claude-plugin)

Comprehensive Claude Code skills for developing [yFiles for HTML](https://www.yworks.com/products/yfiles-for-html) applications.

**Install:**

```bash
/plugin install yfiles-for-html@yfiles
```
